# Bulk operations

Bulksheets is a spreadsheet-based tool used to manage sponsored ads campaigns via bulk operations.

A campaign filter is now available for Sponsored Ads exports in bulk operations, making it easier to scope exported data to specific campaigns.

DSP bulk operations now include a new read-only Creative Association Status column, surfacing creative association state directly in bulk sheets.
